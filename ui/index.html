Library

Every macro you have saved. Each one keeps its own steps, target window and run history, and changes save as you make them.

    One pass

      Step inspector

      Every number a step owns, with its zone and timing drawn as you change them. Edits save as you make them.

      Recorder

      For drags and sweeps where the path matters. Press Ctrl+Shift+R over the app to start and again to stop, then trim the idle edges and smooth the shaky parts.

      Run log

      The last 30 runs, with per-step timing, guard results, sampled points and why each run ended.

      Macro settings

      Target window, loop policy and humanization for the open macro.

      Hotkeys

      Select a row and press the new combination. Clashes with common game bindings are flagged before they take effect.

      Emergency stop keys are only claimed while a macro runs, so the game keeps Esc the rest of the time.

      App and updates

      Overlay, sound and update settings that apply to every macro.
